# Finance Tracker v2.2.4 — macOS installation

1. Unzip `FinanceTracker-v2.2.4.zip` on the Mac.
2. Double-click **Build Finance Tracker Installer.command**.
3. This creates `FinanceTracker-v2.2.4-macOS.pkg` using Apple's `pkgbuild` and `productbuild` tools.
4. Double-click the `.pkg` and complete the normal macOS Installer process.
5. Open Finance Tracker Settings/System Status and confirm **Version 2.2.4**.

Upgrades preserve `/Applications/finance_tracker/data` and create a pre-upgrade database backup when an existing database is present.
